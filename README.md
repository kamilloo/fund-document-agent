# Fund Document Agent

A small TypeScript/Mastra project built as part of technical interview preparation for an AI/backend engineering role.

The goal is to evolve this project from a simple document-search assistant into a production-oriented AI system covering:

- AI agents
- RAG
- semantic search
- embeddings
- evaluation
- LLM-as-judge
- LLMOps
- observability
- reliability
- system design

## Current Scope

Day 1 focuses on the basic architecture and tool boundary.

Current flow:

```text
User question
    ↓
Mastra Agent
    ↓
Search Documents Tool
    ↓
Application Service
    ↓
In-Memory Repository
    ↓
Matching Documents
```

The current document search is based on simple substring matching.

Example:

```text
Query:
management fee

Result:
The management fee shall be 2% of committed capital annually.
```

## Day 2 — Chunking and Vector Search

Day 2 introduces the foundations of semantic retrieval.

Implemented concepts:

- document chunking
- chunk metadata
- cosine similarity
- in-memory vector search
- top-k retrieval

Documents are split into smaller chunks before retrieval.

Example:

```text
## Management Fees

The management fee shall be 2% of committed capital annually.
The fee is calculated quarterly and paid at the end of each quarter.
```

The project now contains a `DocumentChunk` model similar to:

```ts
export type DocumentChunk = {
  id: string;
  documentId: string;
  content: string;
  position: number;
  section?: string;
  page?: number;
  embedding?: number[];
};
```

The current retrieval flow is:

```text
Document
   ↓
Chunking
   ↓
Document chunks
   ↓
Vector representation
   ↓
Cosine similarity
   ↓
Sort by similarity
   ↓
Top-k chunks
```

Cosine similarity is used to compare a query vector with stored chunk vectors.

Example:

```text
Query vector: [1, 0, 0]

Management fee              → 0.9986
Investment territory        → 0.1104
Related party transactions  → 0.0000
```

This is currently an in-memory implementation using manually defined vectors.

The next step is to replace the fake vectors with embeddings generated by a real local embedding model so the system can perform genuine semantic retrieval.

## Running the Project

Install dependencies:

```bash
npm install
```

Start Mastra Studio:

```bash
npm run dev
```

Mastra Studio should be available at:

```text
http://localhost:4111
```

## OpenAI Configuration

To use a real OpenAI model, create a `.env` file:

```bash
OPENAI_API_KEY=your_api_key
```

Do not commit `.env`.
